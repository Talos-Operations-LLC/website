# Hero direction studies

Three local animated concepts for Ethan to compare. These do not change the current
homepage and are outside Netlify's public/ publish directory.

Run from the repository root:

    python3 -m http.server 8001 --bind 127.0.0.1 --directory designs/hero-concepts

Open http://localhost:8001/. The comparison tabs switch between Orbit, Daylight,
and Signal. Demo links point to the existing website preview on localhost:8000.

The shared globe uses a reduced copy of the site's existing geographic dot data.
These are visual prototypes; record UI and status motion are illustrative samples.
Choose a direction before merging any of these into public/.
