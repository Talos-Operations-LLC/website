# Website

Public website for Fee Simple, built by Talos Operations LLC.

## Stack

Astro, built to static HTML. One dependency (`astro`, exact pin). See `BUILD.md`.

## Structure

| Path | Purpose |
| --- | --- |
| `src/pages/` | One file per page; the path is the URL |
| `src/layouts/Base.astro` | Shared head, meta, canonical, JSON-LD, nav, footer |
| `src/components/` | Nav, footer, and the article template for /learn/ and /for/ |
| `src/content/` | The /learn/ and /for/ pages, in Markdown |
| `src/lib/` | Page lists for the hub, sitemap and llms.txt |
| `public/` | Copied to the site as-is: favicon, `assets/`, `demo/` |
| `public/assets/css/` | `site.css` (theme, header, footer, loaded by the layout on every page) plus one stylesheet per page type: `home.css`, `legal.css`, `content.css` (learn, for, hub, 404) |
| `public/assets/js/` | `home.js` (the homepage: dust globe, panels, the two forms) |
| `public/assets/data/` | `hero-geometry.json` (land dots for the homepage dust globe) |
| `public/assets/images/` | Logo and icons (the browser ICO stays at `public/favicon.ico`) |
| `public/demo/` | The Fee Simple workbench snapshot at /demo; see `docs/demo.md` |
| `docs/FACTS.md` | Source for every factual claim on the site |
| `docs/demo.md` | What the demo is and how it is wired in |
| `tools/` | Optional Python helpers: `check_site.py`, `gen_hero_geo.py` |
| `netlify.toml` | Build command, security headers, redirects |

The retired coverage page and its map assets are removed. Old coverage and
ledger URLs redirect to the homepage. The homepage keeps a globe, now drawn in dust.

## Local development

The Terms page covers the website, Fee Simple app and demo. Lead-sale terms
stay in their separate agreements. The website is the sole maintained source
of full policy text; the app links here. Preserve published versions in Git,
and coordinate material changes with the app's terms/acceptance version.
The November 17 Terms and Privacy Policy start from the latest versions on
Internal > Agreements (Terms v3, with Josh's November 16 changes) and add the
two website forms. Paste the same text there as new versions whenever these
pages change. Firm-offboarding and the app acceptance release remain tracked
in the Fee Simple legal review.

The homepage is one dark screen: a dust globe on the left, the brand bottom
right, and two panels that open in place (Talk to us and Early access). Both
forms are Netlify Forms (`talk` and `early-access`); `home.js` posts them in the
background, and Netlify's form notification emails them to
info@talosoperations.com. Type is the device's own font with the wordmark in
Archivo Black; DM Mono for small labels.

```
npm ci
npm run dev
```

## Check the build

```
npm run build
python3 tools/check_site.py
```

The globe sways on its own and leans toward the mouse. On slow machines it
draws half its dust, then a single still frame; with reduced motion it holds still.
The USA tour resumes after ten seconds without interaction. Pause animation
stops automatic motion until Resume animation is selected. With the canvas
focused, arrow keys rotate, Q/E roll, Home resets, and Escape resumes.
Reduced-motion mode renders a static map until keyboard exploration, then responds
without inertia or automatic resuming.

All page templates include a keyboard skip link to the main content.

## Deployment

Connected to Netlify — every push to `main` builds and deploys automatically.
