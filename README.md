# Website

Public website for Fee Simple, built by Talos Operations LLC.

## Stack

Astro, built to static HTML. One dependency (`astro`, exact pin). See `BUILD.md`.

## Structure

| Path | Purpose |
| --- | --- |
| `src/pages/` | One file per page; the path is the URL |
| `src/layouts/Base.astro` | Shared head, meta, canonical, JSON-LD, nav, footer |
| `src/components/` | Nav, footer, and the article template for /learn/ and /for/ |
| `src/content/` | The /learn/ and /for/ pages, in Markdown |
| `src/lib/` | Page lists for the hub, sitemap and llms.txt |
| `public/` | Copied to the site as-is: favicon, `assets/`, `demo/` |
| `public/assets/css/` | `site.css` (theme, header, footer, loaded by the layout on every page) plus one stylesheet per page type: `home.css`, `coverage.css`, `legal.css`, `content.css` (learn, for, hub, 404) |
| `public/assets/js/` | `hero.js` (the globe), `home-motion.js` (homepage reveals), and `coverage.js` (the county map) |
| `public/assets/data/` | `hero-geometry.json`, `county-map.json`, `coverage.json` (county statuses) |
| `public/assets/images/` | Logo and icons (the browser ICO stays at `public/favicon.ico`) |
| `public/demo/` | The Fee Simple workbench snapshot at /demo; see `docs/demo.md` |
| `docs/FACTS.md` | Source for every factual claim on the site |
| `docs/demo.md` | What the demo is and how it is wired in |
| `tools/` | Optional Python helpers: `check_site.py`, `gen_hero_geo.py` |
| `netlify.toml` | Build command, security headers, redirects |

## Where to edit

| Change | File |
| --- | --- |
| Homepage text and signup form | `src/pages/index.astro` |

| Learn and audience articles | `src/content/learn/`, `src/content/for/` |
| Learn page layout | `src/components/Article.astro`, `public/assets/css/content.css` |
| Homepage header and footer | `src/pages/index.astro`, `public/assets/css/home.css`; the footer's layout styles are shared, in `public/assets/css/site.css` |
| Other page headers and footers | `src/components/Nav.astro`, `src/components/Footer.astro`; their styles in `public/assets/css/site.css`. Coverage, Learn, Privacy, and Terms use home-only navigation and the full homepage footer. |
| Legal text | `src/pages/privacy.astro`, `src/pages/terms.astro` |
| Sitemap, robots, llms.txt | Built from `src/lib/site.ts` and the content entries |

## Local development

The homepage uses the approved adaptive Wider layout automatically. Desktop sizing
in `public/assets/css/home.css` scales with viewport width and height; mobile keeps
its stacked layout. No comparison switch or globe zoom controls are shipped.

```
npm ci
npm run dev
```

## Check the build

```
npm run build
python3 tools/check_site.py
node --test tools/globe-rotation.test.mjs tools/hero-interaction.test.mjs
```

The globe supports free dragging, momentum, and hover particle movement.
Drag directly to rotate; touch allows horizontal drags and vertical page scrolling.
The USA tour resumes after ten seconds without interaction. With the canvas
focused, arrow keys rotate, Q/E roll, Home resets, and Escape resumes.
Reduced-motion mode renders a static map until keyboard exploration, then responds
without inertia or automatic resuming.

## Deployment

Connected to Netlify — every push to `main` builds and deploys automatically.
