# Website

Public website for Fee Simple, built by Talos Operations LLC.

## Stack

Astro, built to static HTML. One dependency (`astro`, exact pin). See `BUILD.md`.

## Structure

| Path | Purpose |
| --- | --- |
| `src/pages/` | One file per page; the path is the URL |
| `src/layouts/Base.astro` | Shared head, meta, canonical, JSON-LD, nav, footer |
| `src/components/` | Nav, footer, and the article template for /learn/ and /for/ |
| `src/content/` | The /learn/ and /for/ pages, in Markdown |
| `src/lib/` | Page lists for the hub, sitemap and llms.txt |
| `public/` | Copied to the site as-is: favicon, `assets/`, `demo/` |
| `public/assets/css/` | `site.css` (theme, header, footer, loaded by the layout on every page) plus one stylesheet per page type: `home.css`, `coverage.css`, `legal.css`, `content.css` (learn, for, hub, 404) |
| `public/assets/js/` | `hero.js` (the globe) and `coverage.js` (the county map) |
| `public/assets/data/` | `hero-geometry.json`, `county-map.json`, `coverage.json` (county statuses and stats) |
| `public/assets/images/` | Logo and icons (the browser ICO stays at `public/favicon.ico`) |
| `public/demo/` | The temporary product demo at /demo; see `docs/demo.md` |
| `docs/FACTS.md` | Source for every factual claim on the site |
| `docs/demo.md` | What the demo is and how it is wired in |
| `tools/` | Optional Python helpers: `check_site.py`, `gen_hero_geo.py` |
| `netlify.toml` | Build command, security headers, redirects |

## Where to edit

| Change | File |
| --- | --- |
| Homepage text and signup form | `src/pages/index.astro` |
| Homepage layout | `public/assets/css/home.css` |
| Globe animation, timing, interaction | `public/assets/js/hero.js` |
| Globe dot positions | `public/assets/data/hero-geometry.json` (generated by `tools/gen_hero_geo.py`) |
| Coverage page content | `src/pages/coverage.astro` |
| Coverage map appearance and interactions | `public/assets/css/coverage.css`, `public/assets/js/coverage.js` |
| County statuses and displayed statistics | `public/assets/data/coverage.json` |
| Learn and audience articles | `src/content/learn/`, `src/content/for/` |
| Learn page layout | `src/components/Article.astro`, `public/assets/css/content.css` |
| Header and footer | `src/components/Nav.astro`, `src/components/Footer.astro`; their styles in `public/assets/css/site.css` |
| Legal text | `src/pages/privacy.astro`, `src/pages/terms.astro` |
| Sitemap, robots, llms.txt | Built from `src/lib/site.ts` and the content entries |

## Local development

```

npm run dev
```

## Check the build

```
npm run build
python3 tools/check_site.py
```

## Deployment

Connected to Netlify — every push to `main` builds and deploys automatically.
